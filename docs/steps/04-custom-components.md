# Шаг 04. Свои компоненты в components/custom и витрина

## Контекст

Прочитай `CLAUDE.md` и раздел 8 в `docs/target-design.md`. Каркас и маршруты готовы (шаг 03). Теперь нужен набор своих компонентов, из которых будут собираться все экраны. Все они лежат в `src/components/custom/` и собираются **только** из компонентов `src/components/ui` и утилит Tailwind для раскладки.

## Задача

### 1. Компоненты

Один файл — один компонент (`kebab-case.tsx`, экспорт `PascalCase`). У каждого типизированные props и короткий JSDoc с примером.

| Компонент          | Требования                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `page-header`      | `title`, `description?`, `actions?` (справа; основная кнопка — одна), `meta?` под заголовком (например статус и номер). Заголовок `text-2xl font-semibold`                                                                                                                                                                                                                                                                                                                                  |
| `data-table`       | Обёртка TanStack Table над shadcn `Table`. Сортировка по клику на заголовок, пагинация (shadcn `Pagination`), выбор видимых колонок, панель фильтров (слот), строка-ссылка на карточку. **Состояние сортировки, фильтров и страницы хранится в query-параметрах URL.** Состояния: загрузка (`Skeleton` в форме строк), пусто (`Empty` с действием), ошибка (`Alert`). Колонки с суммами выравниваются вправо. Кнопка «Выгрузить в Excel» (xlsx через `exceljs` или `xlsx` из npm, не с CDN) |
| `money`            | Вывод `Money` через `formatMoney`, `tabular-nums`, моноширинные цифры, без цвета. Проп `currency`                                                                                                                                                                                                                                                                                                                                                                                           |
| `money-input`      | На основе `Input`/`InputGroup`: ввод с разделителями разрядов, запятая или точка как десятичный разделитель, суффикс валюты; наружу отдаёт строку `"1234.50"`                                                                                                                                                                                                                                                                                                                               |
| `currency-select`  | `Select` по `CurrencyCode`, можно ограничить списком                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `date-field`       | `Popover` + `Calendar` + ввод с клавиатуры `ДД.ММ.ГГГГ`; значение `IsoDate`                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `status-badge`     | Принимает сущность и статус, подпись из `messages`, вариант стандартного `Badge` из одной таблицы соответствия: финальные (`closed`, `executed`, `confirmed`) — `default`; требующие действия — `outline`; в работе — `secondary`; `needs_correction` — `destructive`. Своих цветов нет                                                                                                                                                                                                     |
| `description-list` | Сетка «подпись — значение» в `Card`, 1 или 2 колонки, пустое значение показывается как `—`                                                                                                                                                                                                                                                                                                                                                                                                  |
| `form-section`     | Заголовок раздела формы, описание, поля внутри на `Field`; разделитель между секциями                                                                                                                                                                                                                                                                                                                                                                                                       |
| `file-upload`      | Зона выбора файлов (кнопка + drag-and-drop), список файлов: имя, размер, тип документа (`Select`), удалить. На этапе прототипа файлы «загружаются» в память с имитацией прогресса (`Progress`)                                                                                                                                                                                                                                                                                              |
| `file-list`        | Список прикреплённых файлов с иконкой типа, размером, датой и кнопкой «Скачать»                                                                                                                                                                                                                                                                                                                                                                                                             |
| `confirm-dialog`   | `AlertDialog`: заголовок, описание последствий, кнопка действия (`destructive` для опасных). Хук `useConfirm()` для вызова из кода                                                                                                                                                                                                                                                                                                                                                          |
| `entity-combobox`  | `Popover` + `Command`: поиск и выбор из списка (контрагент, плательщик, поставщик), опционально пункт «Добавить новый…»                                                                                                                                                                                                                                                                                                                                                                     |
| `stat`             | `Card` с подписью, значением (`Money` или числом) и необязательной подписью-пояснением                                                                                                                                                                                                                                                                                                                                                                                                      |
| `status-timeline`  | Вертикальная история статусов: статус, кто и когда, комментарий                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `section-card`     | `Card` с заголовком блока (`text-base font-semibold`), необязательными действиями справа и контентом. Карточки не вкладываются                                                                                                                                                                                                                                                                                                                                                              |

Если какому-то компоненту нужен стандартный shadcn-компонент, которого ещё нет, добавь его через `shadcn add` и внеси в `scripts/ui-components.json`. Править файлы в `ui` нельзя.

### 2. Витрина `/dev/components`

Страница, доступная только при `NODE_ENV !== 'production'`. На ней каждый компонент показан во всех состояниях на данных из моков:

- `data-table` с загрузкой, пустым списком, ошибкой и данными;
- `status-badge` для всех статусов всех сущностей;
- формы с ошибками валидации.

Это рабочий инструмент для проверки единообразия: на витрине сразу видно, если два похожих элемента выглядят по-разному.

### 3. Обновить заготовки

Замени временный заголовок из шага 03 на `page-header` во всех заготовках страниц.

## Правила (проверяются на ревью)

- В `custom` нет переопределения цветов, скругления и теней ui-компонентов через `className`. Нет произвольных значений Tailwind вроде `text-[13px]` или `#hex`.
- Отступы: между блоками `gap-6`, внутри блока `gap-4`, подпись и поле `gap-2`.
- Типографика из четырёх уровней (раздел 8.2).
- Все тексты из `messages/ru.ts`.

## Как проверить

- `/dev/components` открывается, все компоненты видны в светлой и тёмной теме.
- На `data-table` сортировка и страница сохраняются в URL: после перезагрузки страницы состояние то же.
- `money-input` при вводе `1234567,8` показывает `1 234 567,8`, а в форму отдаёт `"1234567.80"`.
- `pnpm check` проходит, `pnpm check:ui` подтверждает, что `components/ui` не изменён.
