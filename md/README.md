# Пошаговые задания для Claude Code

Каждый файл `NN-*.md` — одно законченное задание. Порядок работы:

1. Откройте новый репозиторий в VS Code и запустите Claude Code.
2. Передайте ему файл шага целиком: вставьте текст или напишите «выполни задание из steps/NN-....md», предварительно положив файл в репозиторий.
3. Когда Claude Code закончит, пройдите по пункту «Как проверить» в конце файла. Если всё сходится, сделайте коммит и переходите к следующему шагу.
4. Если что-то не так, опишите это Claude Code в той же сессии. Если шаг сильно разошёлся с заданием, напишите мне в тред: я поправлю задание.

Целевая архитектура описана в `financial-systems-target-design.md`. Шаг 01 кладёт её в репозиторий как `docs/target-design.md`, чтобы Claude Code мог на неё ссылаться.

| --------------------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------- |

| [02](02-domain-and-mocks.md)      | Типы предметной области, словарь русских подписей, тестовые данные, слой доступа к данным на моках         | готов                  |
| [03](03-app-shell-and-routing.md) | Разделы `/client` и `/manager`, имитация входа, общий каркас (меню, крошки, профиль)                       | готов                  |
| [04](04-custom-components.md)     | Набор своих компонентов в `components/custom` и страница-витрина `/dev/components`                         | готов                  |

| 06                                | Остальные экраны клиента на моках                                                                          | будет после приёмки 05 |

**После шага 05 остановка.** Вы смотрите три шаблона и говорите, что поменять. Остальные экраны делаются по принятому образцу.

## Этап 2. Настоящий бэкенд

Задания появятся после этапа 1:

- PostgreSQL и Drizzle;
- Better Auth: логин, временные пароли, TOTP;
- книга проводок;
- калькуляторы;
- S3;
- курсы ЦБ и НБ РК;
- деплой.

Моки заменяются настоящими данными без изменения экранов. Для этого в шаге 02 закладывается слой доступа к данным.
